09. 무엇이 그려지지 않나

캔버스는 픽셀을 읽을 수 있다. 그래서 브라우저는 읽히면 안 되는 것을 애초에 그리지 않는다. 왼쪽이 실제 DOM 이고 오른쪽이 캔버스다.

1. 같은 출처 이미지와 교차 출처 이미지

2. 방문한 링크와 방문하지 않은 링크

3. 시스템 색상

4. 맞춤법 검사 밑줄

5. 교차 출처 iframe

각 칸 아래 줄은 그 캔버스에서 toDataURL() 을 실제로 불러 본 결과다. 이 API 는 위험한 내용을 그리지 않는 쪽을 택하므로, 대개 캔버스는 오염되지 않고 해당 부분만 빠진다.
