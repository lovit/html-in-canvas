18. 여러 문서를 한 판에

살아 있는 문서 열두 개를 무한 캔버스에 늘어놓는다. 화면에 걸치는 것만 그리고, 바뀐 것만 다시 그린다. 04 에서 배운 changedElements 를 처음으로 필요해서 쓴다.

보기

캔버스를 끌면 움직이고, 휠을 굴리면 확대·축소됩니다.

그리는 방법

둘 다 끄면 매 프레임 열두 장을 전부 다시 그립니다.

측정값
화면에 걸친 패널
—
이번 paint 에서 그린 것
—
최근 20프레임 평균
—
changedElements
—
paint 횟수
0

패널 세 개에만 시계를 넣었습니다. 나머지 아홉 개는 내용이 바뀌지 않으므로 changedElements 에 올라오지 않고, 다시 그릴 이유도 없습니다.
